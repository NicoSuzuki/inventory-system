# Inventory Management System (Backend)

This is a Node.js + Express + MySQL backend project where I’m building an Inventory Management System from scratch as part of my **#SundayCodingJourney**.

---

## 🚀 Features (so far)

- Product CRUD (create, read, update, delete)  
- User CRUD (with hashed passwords, validations, and role field)  
- MySQL database connection  
- Organized MVC structure  

---

## 🛠️ Tech Stack

- Node.js  
- Express.js  
- MySQL / MySQL Workbench  
- bcryptjs  
- dotenv  

---

## 📌 Upcoming features

- Authentication (JWT)  
- Role-based authorization  
- Order system + stock movement  
- Deployment  

---

## 📦 How to run

1️⃣ Clone the repository
  -bash
  -git clone https://github.com/NicoSuzuki/inventory-system.git
  -cd inventory-system

2️⃣ Install dependencies
  -bash
  -npm install

3️⃣ Create a .env file in the root folder
  -DB_HOST=localhost
  -DB_USER=your_user
  -DB_PASSWORD=your_password
  -DB_NAME=inventory_db
  -DB_PORT=3306
  -PORT=3000

4️⃣ Start the development server
  -npm run dev

5️⃣ API will be running at
  -http://localhost:3000
